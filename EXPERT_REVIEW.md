# Expert Review Scope

This repository is intended for technical review.

Reviewers should distinguish:

1. mathematical properties of the supplied invariant;
2. assumptions introduced by the phenomenological coupling;
3. numerical correctness of the implementation;
4. physical validity of the cosmological model;
5. compatibility with observational data.

The present repository establishes items 1-3 only to the extent covered by its source code and tests.

A useful independent review should reproduce the numerical outputs and, if warranted, implement the model in a full Boltzmann framework before drawing observational conclusions.
